# 刊创科技写作平台 · 安装包

厦门刊创研究院内部使用的学术写作桌面应用，基于开源项目 Open-Science（Apache-2.0）二次开发。本仓库只存放安装包和软件内更新文件，不含源代码。

## 安装（macOS，Apple 芯片）

1. 打开 [最新版本](https://github.com/WEISE957/kanchuang-releases/releases/latest)，下载 `kanchuang-open-science-<版本>-mac-arm64.dmg`。
2. 双击 dmg，把应用拖进「应用程序」。
3. 第一次打开：在「应用程序」里**右键 → 打开 → 打开**（安装包没有 Apple 公证，直接双击会被系统拦下）。
4. 进「设置 → 中转站」填写中转站地址和 API key。

## 更新

装好之后不用再来这里下载：软件会自动检查新版本，也可以在「设置 → 通用」点「立即检查」，有新版本时点「更新到 x.y.z」，下载完成后重启即可。
